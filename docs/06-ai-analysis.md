# تحلیل هوش مصنوعی

## نحوه کار

سیستم تحلیل SWOT از هوش مصنوعی برای ارزیابی پاسخ‌های دانشجویان استفاده می‌کند.

## جریان تحلیل

```
1. دانشجو پرسشنامه را تکمیل می‌کند
   ↓
2. پاسخ‌ها به سرور ارسال می‌شود
   ↓
3. AI Service فعال می‌شود
   ↓
4. Prompt فارسی ساخته می‌شود
   ↓
5. مدل AI تحلیل می‌کند (5-10 ثانیه)
   ↓
6. نتایج Parse و Validate می‌شود
   ↓
7. در پایگاه داده ذخیره می‌شود
   ↓
8. به دانشجو نمایش داده می‌شود
```

## مدل‌های AI

### گزینه 1: Ollama (محلی)

**مزایا:**
- ✅ رایگان
- ✅ بدون نیاز به اینترنت
- ✅ حریم خصوصی کامل
- ✅ بدون محدودیت

**مدل‌های پیشنهادی:**
- `gemma3:1b` - سریع (815 MB)
- `qwen3:8b` - کیفیت خوب (5.2 GB)
- `gemma3:12b` - کیفیت عالی (8.1 GB)

**نصب:**
```bash
# دانلود Ollama
# Windows: https://ollama.ai/download

# دانلود مدل
ollama pull gemma3:1b
```

### گزینه 2: OpenRouter (ابری)

**مزایا:**
- ✅ دسترسی به 400+ مدل
- ✅ بدون نیاز به سخت‌افزار قوی
- ✅ کیفیت بالا
- ✅ مقیاس‌پذیر

**هزینه:**
- Llama 3.3 70B: ~$0.50 / 1M token
- GPT-4: ~$30 / 1M token
- Claude 3.5: ~$15 / 1M token

**تنظیم:**
```json
{
  "active_provider": "openrouter",
  "providers": {
    "openrouter": {
      "api_key": "YOUR_KEY",
      "model": "meta-llama/llama-3.3-70b-instruct"
    }
  }
}
```

## خروجی تحلیل

### 1. نوع شخصیت
طبقه‌بندی بر اساس ویژگی‌ها:
- **متفکر استراتژیک**: تفکر بلندمدت و برنامه‌ریزی
- **رهبر خلاق**: نوآوری و رهبری
- **حل‌کننده مسئله**: تحلیل و حل مسئله
- **یادگیرنده پویا**: یادگیری مداوم
- **فرد انعطاف‌پذیر**: سازگاری بالا

### 2. امتیاز کلی (0-100)
- **80-100**: عالی - خودآگاهی بالا
- **60-79**: خوب - در مسیر درست
- **40-59**: متوسط - نیاز به تمرکز
- **0-39**: ضعیف - نیاز به کار بیشتر

### 3. ویژگی‌های شخصیتی

#### اعتماد به نفس (Confidence)
- اطمینان به توانایی‌ها
- جرات در تصمیم‌گیری
- ابراز وجود

#### خودآگاهی (Self-Awareness)
- شناخت نقاط قوت و ضعف
- درک احساسات
- بینش درونی

#### ذهنیت رشد (Growth Mindset)
- باز بودن به یادگیری
- پذیرش چالش‌ها
- استقبال از بازخورد

#### انعطاف‌پذیری (Resilience)
- مقاومت در برابر مشکلات
- بازگشت از شکست
- سازگاری با تغییر

#### تفکر استراتژیک (Strategic Thinking)
- برنامه‌ریزی بلندمدت
- تحلیل فرصت‌ها
- تصمیم‌گیری هوشمند

### 4. نقاط قوت کلیدی
3 نقطه قوت اصلی که باید تقویت شوند

### 5. زمینه‌های بهبود
موارد نیازمند توسعه و تمرین

### 6. توصیه‌ها
پیشنهادات عملی و قابل اجرا:
- شرکت در کارگاه‌ها
- مطالعه کتاب‌ها
- تمرین مهارت‌ها
- جستجوی منتور

### 7. پیشنهادات شغلی
مسیرهای شغلی متناسب با شخصیت:
- بر اساس نقاط قوت
- متناسب با علایق
- قابل دستیابی
