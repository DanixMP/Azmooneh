# مقدمه

## درباره سیستم

این سیستم یک پلتفرم آموزشی جامع است که دو قابلیت اصلی را ارائه می‌دهد:

### 1. سیستم آزمون آنلاین
- ایجاد و مدیریت آزمون‌ها توسط اساتید
- انواع مختلف سوالات (تک گزینه‌ای، چند گزینه‌ای، صحیح/غلط، تشریحی)
- نمره‌دهی خودکار
- مشاهده نتایج و گزارش‌ها

### 2. تحلیل SWOT با هوش مصنوعی
- پرسشنامه SWOT برای دانشجویان
- تحلیل خودکار با هوش مصنوعی
- ارزیابی شخصیت و ویژگی‌های روانشناختی
- پیشنهادات شغلی شخصی‌سازی شده

## تکنولوژی‌های استفاده شده

### Backend
- **Django 6.0** - فریمورک وب
- **Django REST Framework** - API
- **SQLite/PostgreSQL** - پایگاه داده
- **JWT** - احراز هویت

### Frontend
- **React 18** - کتابخانه UI
- **TypeScript** - زبان برنامه‌نویسی
- **Vite** - ابزار ساخت
- **Tailwind CSS** - استایل‌دهی
- **Framer Motion** - انیمیشن

### هوش مصنوعی
- **Ollama** - اجرای مدل‌های محلی
- **OpenRouter** - دسترسی به مدل‌های ابری
- **Gemma 3** / **Qwen 3** - مدل‌های زبانی

## نقش‌های کاربری

### دانشجو
- شرکت در آزمون‌ها
- تکمیل تحلیل SWOT
- مشاهده نتایج و پیشنهادات

### استاد
- ایجاد و مدیریت آزمون‌ها
- نمره‌دهی به پاسخ‌های تشریحی
- مشاهده تحلیل‌های SWOT دانشجویان
- ارائه مشاوره بر اساس نتایج
