## درباره این پروژه

این سیستم یک پلتفرم جامع برای مدیریت آزمون‌ها و تحلیل SWOT دانشجویان است که با قابلیت‌های هوش مصنوعی تقویت شده است.

## ویژگی‌های اصلی

- ✅ مدیریت آزمون‌های آنلاین
- ✅ تحلیل SWOT با هوش مصنوعی
- ✅ ارزیابی شخصیت دانشجویان
- ✅ پیشنهادات شغلی هوشمند
- ✅ رابط کاربری فارسی

## شروع سریع

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt
npm install

# اجرای مهاجرت‌ها
python manage.py migrate

# اجرای سرور
python manage.py runserver
npm run dev
```

برای اطلاعات بیشتر، به بخش [راهنمای نصب](./03-installation.md) مراجعه کنید.
